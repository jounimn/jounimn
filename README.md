### ⚙️ How I build

```mermaid
flowchart LR
    A[💡 Idea] --> B[🧠 Brainstorm<br/>the spec]
    B --> C[📋 Plan in<br/>small tasks]
    C --> D[🔴 Failing test]
    D --> E[🟢 Make it pass]
    E --> F[🔍 Review by a<br/>second agent]
    F -->|needs fixes| D
    F -->|clean| G[🚀 Ship]
```

> I pair with AI agents the way I'd pair with a senior dev: every change gets a plan first, a test second, code third, and a review before it merges.
